# StudyFlow – Student Daily Routine Planner

Modern responsive student productivity dashboard built only with HTML5, CSS3 and Vanilla JavaScript.

## Run
Open `index.html` in a current browser. No backend or server is required.

## Included
- Responsive sidebar and mobile navigation
- Live clock/date
- Daily routine timeline with add/edit/delete/complete
- Separate daily task manager
- Search, status, priority and category filters
- Previous/Today/Next date navigation
- Dynamic statistics and progress dashboard
- Study hours calculation
- Dark/light theme stored in localStorage
- Toast notifications and confirmation dialogs
- Empty states and realistic first-visit sample data
- Profile/settings stored locally
- Accessible labels, focus states, semantic HTML, keyboard Escape for modals

## Local Storage
Data is saved in the browser under `studyflow-app-v1`, so it persists after refresh/reopen on the same browser/device. There is no server sync.
